# AI Collaboration Log

## Tools used
- ChatGPT

## A prompt that worked well
I pasted my MusicLibrary and Song classes and asked for a feature that matched the CIS 25 requirements.

It worked well because the AI could see the existing project structure and coding style.

## A prompt that did not work
I first asked for a playlist system, but the AI suggested too many new classes and extra complexity.

I simplified the feature to removing songs from the library.

## Code I rejected
The AI suggested using iterators and advanced STL features.

I rejected that and used a normal indexed loop because it matched the style used in class.

## What I'd do differently next time
I would write the specification earlier before asking the AI for implementation details.

## Fresh-conversation review
The AI review suggested checking edge cases for empty libraries and missing songs.

I added tests for those cases.

I rejected suggestions to refactor the whole MusicLibrary class because the feature was supposed to stay small and focused.
