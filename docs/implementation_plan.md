# Implementation Plan

## Feature 1: Add Song

User selects "Add Song" from menu  
Prompts the user for song title, artist, and duration.  
Creates a Song object and adds it to the music library.  
Displays confirmation after adding.


## Feature 2: Play Song

User selects "Play Song"  
User inputs song title.  
Program searches for the song and displays a "Now Playing" message.  
If not found, shows an error message.

## Feature 3: Display All Songs

User selects "Display All Songs"  
Loops through all songs in the library.  
Prints title, artist, and duration for each song.

## Feature 4: Search Songs

User selects "Search Songs"  
User enters title or artist.  
Program filters songs and displays matching results.

## Feature 5: Playlist Management

User selects "Manage Playlists"  
Allows user to create playlists and add songs to them.  
Displays playlist contents.

## Feature 6: Save/Load Library

Program start (load) and exit (save)  
Loads songs from a file when program starts.  
Saves all songs back to the file before exiting.
